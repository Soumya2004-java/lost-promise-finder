# Lost Promise Finder

Lost Promise Finder is a polished Android Studio prototype that turns meeting, class, or chat notes into a clear list of commitments, owners, deadlines, and suggested follow-ups.

## Highlights

- Jetpack Compose and Material 3 UI
- Glassmorphism visual system with a floating cylindrical tab bar
- Dashboard for promises needing attention
- Notes analysis flow with sample promise extraction
- Filters for due soon, upcoming, and completed promises
- Follow-up message suggestions

## Run locally

1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Run the `app` configuration on an emulator or Android device.

The current release is a front-end prototype with demo/local data. Backend persistence, authentication, and live AI processing are not connected yet.
